Nasar & Co – Internal Management Software

A lightweight internal software developed for the CEO of Nasar & Co to manage and track financial activities efficiently. This system allows the user to add and monitor funds, record transactions, and maintain a structured overview of business-related financial data.

The application is designed for personal/internal use, focusing on simplicity, speed, and ease of use rather than complex enterprise features. It provides a straightforward interface for managing essential financial operations without unnecessary overhead.

Key Features:

Add and track funds
Record financial entries and updates
Simple and user-friendly interface
Organized data management for internal use

Note:
This project is intended for private/internal usage and may not include advanced security or multi-user support.
